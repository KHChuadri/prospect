## Files
- `svg/prospect-mark.svg` — primary mark, two colour, on light
- `svg/prospect-mark-reversed.svg` — on dark
- `svg/prospect-mark-mono-black.svg` / `-mono-white.svg` — single colour (print, embroidery, low-contrast grounds)
- `svg/prospect-lockup.svg` / `-reversed.svg` — mark + wordmark, horizontal
- `svg/prospect-app-icon.svg` — dark tile, sharp 7% corners
- `svg/favicon.svg` — same tile at favicon scale
- `png/` — raster exports (transparent for marks, opaque tile for icons)

## Rules
- Clearspace: 25% of the mark's width on all four sides.
- Minimum sizes: mark 16px; lockup 96px wide. Below that, mark only.
- Two colours only. Never rotate, skew, stretch, recolour, or add a shadow.
- Wordmark is **Space Grotesk 600, tracking -0.035em**. The lockup SVGs use live text — convert to outlines before sending to a printer or any environment without the font installed.
